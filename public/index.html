Bitcoin full node in Rust for server-side operators

Validating peer, compact relational archive, and in-process Electrum (plus optional Esplora REST) in one Linux-first binary—built for wallet backends and infrastructure, not a desktop GUI.

Why this node is different

Most full nodes center a UTXO set and block files. Most Electrum backends are external indexers of another node. rbitcoin does neither.

Relational archive, no UTXO set

Map-free Class A/B/C tables (libbitcoin-class design): packed txs, spend annotations, native scripthash—txindex and Electrum index included in the archive footprint.

Electrum in-process

Self-contained single binary for Electrum self-hosting—and optional Esplora REST—without a second process re-indexing blk files. Wallet clients, not a graphical explorer.

Pure-Rust scripts · modest RAM

Consensus and script verification in Rust on rust-bitcoin (secp256k1 only as crypto primitive). No multi‑GiB dbcache flush pauses on the confirm path.

Operator-order facts

Ballpark figures from a real mainnet archive; tip moves—treat as order of magnitude, not a warranty.

~886 GiB Full archive with txindex + Electrum scripthash Fits ~1 TB-class disks
< ~30 h IBD on a laptop-class host With --milestone 0 (full scripts)
Modest RAM During sync—no multi‑GiB dbcache Confirm is lookup → load → scripts → write

Newer transactions resolve hottest in the segmented tx.index design. Reproducible static musl builds target ordinary Linux hosts. Full details on GitHub.

Who it’s for

Different goals than Bitcoin Core: smaller full archive, single-binary Electrum self-host—not every Core surface.

Built for

  • Wallet-backend operators (Electrum / Esplora clients)
  • Infrastructure that wants a validating node + index in one process
  • Linux servers with ~1 TB-class disk for a full archive
  • Engineers who prefer pure-Rust consensus transparency

Not a fit

  • Desktop wallets, mining, or GUI
  • Pruned / low-disk “lite” nodes
  • Graphical block explorers and catalogue search

Start on signet

Prefer a signet soak before mainnet. On-disk format and APIs are unstable until 1.0. Source and musl builds live on GitHub.
