Why another node?

rbitcoin explores a different way to store and validate Bitcoin’s history, with wallet serving in the same process.

Its design sits between libbitcoin’s relational archive and Bitcoin Core’s block files. Previous outputs come from indexed history, without a separate UTXO database.

Its independent consensus implementation uses Rust, rust-bitcoin types, and libsecp256k1 cryptography: another implementation reading and checking the same chain.

How it was built

Brandon Black, known as Rearden or @reardencode, designed and directed the project. Grok wrote the code, with help from Claude, using grok build and Cursor.

AI made it possible to build a design he had wanted to pursue for years. Hear the story in his conversation with Pleb Underground.

Work on something concrete

Review a consensus edge case. Reproduce a bug. Improve a test or an explanation. Start with contributor setup, then use the issue tracker for non-sensitive work.

Vulnerabilities take a different route: report them privately. Do not put an unfixed exploit in a public pull request.
