About

rbitcoin is a Bitcoin full node in Rust aimed at production server-side use: multi-peer IBD, tip follow, relay, and in-process Electrum / optional Esplora for wallet clients.

Purpose

The design centers a libbitcoin-class relational archive (no UTXO set), pure-Rust consensus on rust-bitcoin, and a single binary for Electrum self-hosting on Linux. Smaller full archive than a Core + separate indexer stack—still full archival, not a pruned lite node.

Origin

The architecture had been gestating for years. The first-party implementation was written with AI assistance (Grok / xAI) under the direction and prompting of Brandon Black (@reardencode). That does not change how seriously consensus, P2P, and Electrum integrity are taken—or how to report bugs. See the node SECURITY.md for authorship and review expectations.

This site

rbitcoin.org is a static marketing site (no backend). Clone the site repository, point a web server document root at public/, and serve—no build step. Product documentation and operator runbooks stay in the node repository.
