Get started

Clone the source and build a reproducible musl binary with Nix. Consensus uses rust-bitcoin and libsecp256k1. Mainnet use is reckless; consensus divergence is likely. Format and public APIs stay unstable until 1.0.

Experimental 0.x. Core pipelines exist. Mainnet use is reckless; consensus divergence is likely. Read the experimental mainnet notes and the operator guide before depending on this binary for real funds or production wallets.

1. Get the source

Clone github.com/reardencode/rbitcoin. The recommended way to produce a portable static binary is Nix with flakes enabled. Pre-built release binaries are not published yet. 

git clone https://github.com/reardencode/rbitcoin.git
cd rbitcoin

2. Reproducible static release (recommended)

This is the reproducible release path. Pinned nixpkgs and Cargo.lock produce fully static, byte-identical rbitcoin-node and rbitcoin-cli binaries (musl) for a given git revision. They run on ordinary Linux hosts with no Nix store and no matching glibc. 

nix build .#rbitcoin-musl
install -m 755 result/bin/rbitcoin-node result/bin/rbitcoin-cli target/release/

Do not ship cargo build --release from inside nix-shell as the operator binary: that links against the Nix store glibc and fails outside the store. See reproducible builds.

3. Signet lab (time-boxed)

Confirm the binary starts, talks to peers, and advances tip before you give it real disk or real funds. 

./target/release/rbitcoin-node --datadir ./datadir-signet --network signet \
  --listen 127.0.0.1:38333 --milestone 200000 --max-run-secs 120

Custom Signets: --signetchallenge and --signetblocktime. Logging and other knobs: OPERATOR.md.

4. Optional surfaces

IBD, tip follow, and P2P stand on their own. Wallet listeners and JSON-RPC are opt-in.

Electrum is a full wallet-client backend in the same process: scripthash history, unconfirmed, broadcast, fees, and silent payment tweaks. Optional Esplora REST covers the same role. Not a graphical explorer. Knobs: OPERATOR.md. 

./target/release/rbitcoin-node --datadir ./datadir-signet --network signet \
  --electrum-listen 127.0.0.1:50001

JSON-RPC (--rpc-listen) is a documented Core-class subset (cookie file or --rpcuser / --rpcpassword). No wallet, mining, or scantxoutset. See docs/rpc.md. 

./target/release/rbitcoin-node --datadir ./datadir-signet --network signet \
  --rpc-listen 127.0.0.1:18332

Put TLS in front if you bind beyond localhost (Electrum, Esplora, or RPC).

5. Hot and cold datadirs

A full archive belongs on 1 TB-class media. Less than 250 GB must stay on fast (hot) storage even with full indexes. The rest of the rarely-read input and witness data can sit on a second volume: 

./target/release/rbitcoin-node --datadir /mnt/nvme/rbtc \
  --datadir-cold /mnt/hdd/rbtc-cold --network signet

--datadir-cold holds Class A inwit.body and inwit.idx/ only. Confirm, spends, heads, and optional scripthash stay on --datadir. Omit the flag and both live in one tree. See OPERATOR.md.

Milestone honesty

Default mainnet --milestone is assumevalid-style: it skips script and signature checks at or below the configured height. Prevouts, double-spend checks, maturity, and fees still run.

Use --milestone 0 for full historical script validation. See the node README for the current default height.

Requirements (order of magnitude)

  • Platform: Linux first. Other operating systems are unproven.
  • Disk: 1 TB-class for a full archive. Keep under 250 GB on hot storage even with full indexes; use --datadir-cold for the rest if you have two volumes.
  • Mode: full archival only—there is no pruning option.
  • Build: Nix with flakes; nix build .#rbitcoin-musl is the reproducible static release (preferred).
  • P2P: BIP324 version 2 only; plan reverse-proxy TLS for Electrum and Esplora if you expose them beyond localhost.
