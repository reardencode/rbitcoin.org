A compact Bitcoin archive, not a UTXO set

Most full nodes keep a UTXO database and a pile of block files. rbitcoin 0.5 keeps a compact full archive instead, and checks scripts in Rust on rust-bitcoin and libsecp256k1. The same process can serve Electrum—including silent payment tweaks—plus Esplora and a slice of Core JSON-RPC.

You can run it on mainnet. The thing to watch is consensus: this is not Core’s interpreter, so it can disagree with Core about what is valid.

What’s different

No coins database. No separate indexer. One Linux process validates, stores the archive, and can talk to wallets.

The archive is the store

Outputs, spends, and a transaction index live in ordinary files. When a block arrives, prevouts come from that archive. There is no UTXO set to keep in RAM and no multi‑GiB dbcache to flush.

Electrum in the same process

History, unconfirmed, broadcast, fees, and silent payment tweaks. Esplora REST is there too. 0.5 spent a lot of work on that serve path. This is a wallet backend, not a block explorer with a search box.

rust-bitcoin · libsecp256k1

Types come from rust-bitcoin. ECDSA and Schnorr go through libsecp256k1. Scripts run in Rust in this tree. There is no second opinion from libbitcoinconsensus.

A slice of Core JSON-RPC

Chain, mempool, raw transactions, fee estimates, and a block template selector. Cookie or user/pass. No wallet, no stratum, no UTXO scanner. For script history, use Electrum.

Storage

Full archival only. The chain grows, so plan on a 1 TB-class disk and don’t wait for a published byte count. If you have an NVMe and a spinning disk, split them.

1 TB-class Full archive, indexes included No prune. The tip moves.
< 250 GB hot Even with full indexes Outputs, spends, heads, optional scripthash
Hot / cold --datadir-cold for a second volume Inputs and witness can live on a spinning disk

Skip --datadir-cold and everything lives in one tree. Sync does not need a multi‑GiB dbcache. 0.5 ships as a GitHub Release; Nix still produces byte-identical musl on Linux.

Who it is for

People who want to validate, keep a full archive, and serve wallets from the same box, and who can live with an independent consensus implementation. It will not prune.

Built for

  • Electrum in-process, including silent payment tweaks
  • A documented slice of JSON-RPC next to the archive
  • Linux with a 1 TB-class disk, and a second volume if you have one

Out of scope

  • Desktop wallets, a GUI, or a stratum/pool stack
  • Pruned or “lite” nodes
  • Block explorers and address search

Why it exists

The interesting part is the store: a compact archive with no UTXO set. Rust consensus and Electrum came with it. The longer version.

Run 0.5

Grab the GitHub Release, or build musl with Nix. Mainnet is fine if you watch consensus. If the node is useful, send some sats.
