Get started

Source and portable builds live on GitHub. Prefer a signet soak before any mainnet cutover—format and APIs are unstable until 1.0.

Not prime time yet. Core pipelines exist, but treat early mainnet as high-scrutiny. Read experimental mainnet and the operator guide before relying on this binary.

1. Get the source

Clone github.com/reardencode/rbitcoin. You need Nix with flakes for the recommended portable build. 

git clone https://github.com/reardencode/rbitcoin.git
cd rbitcoin

2. Portable static release (recommended)

Pinned nixpkgs + Cargo.lock produce a fully static, portable rbitcoin-node / rbitcoin-cli (musl) for ordinary Linux hosts—no matching glibc required on the target. 

nix build .#rbitcoin-musl
install -m 755 result/bin/rbitcoin-node result/bin/rbitcoin-cli target/release/

Do not use cargo build --release inside nix-shell as the operator binary—that links against the Nix store glibc and fails outside the store. Details: reproducible builds.

3. Signet lab (time-boxed)

./target/release/rbitcoin-node --datadir ./datadir-signet --network signet \
  --listen 127.0.0.1:38333 --milestone 200000 --max-run-secs 120

Custom Signets are supported with --signetchallenge and --signetblocktime. Electrum and Esplora listen flags are documented in OPERATOR.md.

Milestone honesty

Default mainnet --milestone (assumevalid-style) skips script/sig checks at or below the configured height. Prevouts, double-spend, maturity, and fees still run.

Use --milestone 0 for full historical script validation. The author prefers validating scripts; the compact storage architecture keeps scripts-on competitive on laptop-class hosts. See the node README for the current default height.

Requirements (order of magnitude)

  • Platform: Linux first (io_uring + map-free fd store; other OSes unproven)
  • Disk: ~886 GiB full archive with txindex + scripthash (~1 TB-class)
  • Mode: full archival only—no pruning option
  • Build: Nix + flakes for musl static (preferred)
